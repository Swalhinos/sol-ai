# SOL.ai — موقع دردشة خاص (Gemini + Groq)

موقع متكامل: واجهة دردشة بأسلوب احترافي + دخول بالتوكن + لوحة تحكم للإدارة.
مفاتيح الذكاء الاصطناعي تبقى في السيرفر ولا تصل للمتصفح أبداً.
المزود الافتراضي Gemini، ويمكن التبديل إلى Groq (أسرع) من إعدادات الأدمن.

يعمل على **Vercel** (خطة Hobby المجانية — بلا كارت بنك) مع تخزين **Vercel KV** (مجاني).

## المتطلبات (مجانية 100%، بلا كارت)
1. حساب GitHub (مجاني) — الكود موجود في `Swalhinos/sol-ai`
2. حساب Vercel (مجاني — سجّل دخول بـ GitHub، بلا كارت)
3. مفتاح Gemini من Google AI Studio (مجاني، بلا كارت)
4. مفتاح Groq من console.groq.com (مجاني، بلا كارت — اختياري، للتبديل إلى Groq)

## النشر على Vercel — خطوة بخطوة

### 1. أنشئ المشروع
- ادخل إلى **vercel.com** وسجّل دخولك بـ **Continue with GitHub**
- **Add New...** ← **Project** ← اختر مستودع `sol-ai` ← **Import**

### 2. أنشئ قاعدة البيانات KV
- في صفحة المشروع ← تبويب **Storage** ← **Create Database** ← اختر **KV**
- أعطها أي اسم ← **Create** ← ستُربط بالمشروع تلقائياً

### 3. أضف المتغيرات السرية
- تبويب **Settings** ← **Environment Variables** ← أضف:
  - `GEMINI_API_KEY` = مفتاح Gemini الخاص بك
  - `GROQ_API_KEY` = مفتاح Groq الخاص بك (اختياري — لازم إلا اخترت مزود Groq)
  - `ADMIN_PASSWORD` = كلمة سر لوحة التحكم (اختر واحدة قوية)
- (متغيرات `KV_REST_API_URL` و `KV_REST_API_TOKEN` تُضاف تلقائياً من خطوة 2)

### 4. انشر
- اضغط **Deploy** — سيعطيك رابطاً مثل `https://sol-ai-xxx.vercel.app`
- افتح الرابط ثم `/admin` وسجّل دخولك بكلمة السر
- **Tokens** ← أنشئ توكن لكل شخص ← انسخ التوكن وأرسله مع الرابط

## اختيار الموديل من واجهة الشات
في أعلى نافذة الشات توجد قائمة لاختيار الموديل: كل مستخدم يختار الموديل الذي يريد (Gemini أو Groq) لكل محادثة، ويُحفظ اختياره في متصفحه. الخيار الافتراضي يأتي من إعدادات الأدمن. أي موديل غير مسموح به يُرفض تلقائياً ويُستعمل الافتراضي.

## لوحة التحكم (/admin)
- **Tokens:** إنشاء / إيقاف / حذف التوكنات، نسخها بضغطة
- **Usage:** عدد الرسائل والتوكنات لكل توكن + الإجمالي
- **Settings:** المزود (Gemini / Groq)، الموديل (مثلاً `gemini-3.5-flash` أو `openai/gpt-oss-120b`)، التعليمات (system prompt)، الحرارة، حد التوكنات، **إعلان** يظهر شريطاً لكل المستخدمين

## ملاحظات
- خطة Vercel المجانية لها حدود سخية (100GB نقل شهرياً، KV مجاني) — تكفي لموقع خاص صغير.
- خطة Gemini المجانية لها حدود (طلبات/يوم) — راقب الاستهلاك من اللوحة.
- لا تضع أي مفتاح (Gemini / Groq) في الكود أبداً — فقط في Environment Variables.

## تحديثات الموقع — لا نسخة قديمة مخزنة (cache)
لكي يرى الزوار دائماً النسخة الجديدة وليست القديمة المخزنة في المتصفح:
- روابط الملفات في `index.html` و `admin.html` تحمل رقم إصدار (`?v=5`) — **ارفع الرقم مع كل نشر**.
- `vercel.json` يفرض `Cache-Control: max-age=0, must-revalidate` على كل الصفحات والملفات.
- ردود الـ API تحمل `Cache-Control: no-store` (لا تُخزَّن أبداً).

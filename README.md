# SOL.ai Web — موقع دردشة خاص بمفتاح Gemini

موقع متكامل: واجهة دردشة بأسلوب احترافي + دخول بالتوكن + لوحة تحكم للإدارة.
مفتاح Gemini يبقى في السيرفر ولا يصل للمتصفح أبداً.

## المتطلبات (مجانية 100%)
1. حساب GitHub (مجاني)
2. حساب Render (مجاني — سجّل دخول بـ GitHub)
3. مفتاح Gemini من Google AI Studio (مجاني)

## النشر على Render — خطوة بخطوة

### 1. ارفع المشروع إلى GitHub
- أنشئ مستودعاً جديداً (New repository) باسم `sol-ai`
- ارفع كل ملفات هذا المجلد إليه (يمكنك السحب والإفلات في موقع GitHub)

### 2. أنشئ الخدمة في Render
- ادخل إلى render.com وسجّل دخولك
- **New +** ← **Web Service** ← اختر مستودع `sol-ai`
- الإعدادات:
  - **Name:** `sol-ai` (سيكون رابطك: `https://sol-ai.onrender.com`)
  - **Runtime:** Node
  - **Build Command:** `npm install`
  - **Start Command:** `npm start`
  - **Instance Type:** Free

### 3. أضف المتغيرات السرية
في صفحة الخدمة ← **Environment** ← أضف:
| Key | Value |
|-----|-------|
| `GEMINI_API_KEY` | مفتاح Gemini الخاص بك |
| `ADMIN_PASSWORD` | كلمة سر لوحة التحكم (اختر واحدة قوية) |

ثم **Save Changes** — سيُعاد النشر تلقائياً.

### 4. فعّل الموقع
- افتح الرابط: `https://sol-ai.onrender.com`
- افتح `https://sol-ai.onrender.com/admin` وسجّل دخولك بكلمة السر
- **Tokens** ← أنشئ توكن لكل شخص (اسم + حد رسائل اختياري)
- انسخ التوكن وأرسله للشخص مع الرابط — يدخل التوكن مرة واحدة ويبدأ الدردشة

## لوحة التحكم (/admin)
- **Tokens:** إنشاء / إيقاف / حذف التوكنات، نسخها بضغطة
- **Usage:** عدد الرسائل والتوكنات لكل توكن + الإجمالي
- **Settings:** الموديل، التعليمات (system prompt)، الحرارة، حد التوكنات، **إعلان** يظهر شريطاً لكل المستخدمين

## ملاحظات مهمة
- الخطة المجانية في Render تُطفئ السيرفر عند الخمول — أول زيارة قد تتأخر ~30 ثانية ثم يعمل طبيعياً.
- خطة Gemini المجانية لها حدود (طلبات/يوم) — راقب الاستهلاك من اللوحة.
- لا تضع مفتاح Gemini في الكود أبداً — فقط في Environment كما هو مشروح.
- البيانات (التوكنات) تُحفظ في `data/` — تُمسح عند إعادة النشر من الصفر (نادر).

## التشغيل محلياً (للتجربة)
```bash
npm install
GEMINI_API_KEY=your_key ADMIN_PASSWORD=secret npm start
# ثم افتح http://localhost:3000
```
